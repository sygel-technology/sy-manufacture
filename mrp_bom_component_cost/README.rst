and its lines.

Configuration
=============

To configure this module, you need to:

1. Go to Settings / Users & Companies / Groups
2. Search the "Costs in bills of materials" group
3. Add the users that should be able to see the costs in bills of
   materials to this group.

Usage
=====

To configure this module, you need to:

1. Go to Manufacturing / Products / Bills of Materials
2. You will be able to see the "Unit Cost" and the "Subtotal cost"
   columns in the component lines
3. You will also be able to see the BOM total cost under the components.
